СВАДЕБНОЕ ПРИГЛАШЕНИЕ — КОНСТАНТИН И ИМЯ

Распакуйте архив целиком и откройте index.html в браузере.
Сайт работает без установки библиотек, PHP и базы данных.

Для GitHub Pages: загрузите index.html, style.css, script.js и папку assets целиком, сохранив её название и структуру.
Не переносите фотографии из assets в корень — иначе изображения не загрузятся.

Дата: 15 мая 2027. Имя невесты, адрес и время пока оставлены заглушками.
В комплекте четыре сгенерированные демонстрационные фотографии и миниатюры.
Галерея поддерживает миниатюры, стрелки, свайпы и полноэкранный просмотр.
